# Camera-Based Tic-Tac-Toe

Neon Tic-Tac-Toe controlled by hand gestures in real time.
Built for ITC Welcome Day.

## Features
- Hand tracking with MediaPipe (pinch = click)
- Play vs computer (Easy / Hard with Minimax)
- Neon UI with pygame

## Run
pip install -r requirements.txt
python main.py

## Controls
Move your hand to aim, pinch thumb + index to click.
